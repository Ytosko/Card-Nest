# Card Nest 1.0.3-beta-f0D3X

`versionCode: 12`

- Opens the native Android contact editor for single-contact export so Android controls the destination account.
- Preserves multiple phone numbers, emails, websites, organization, job title, postal address, and concise WhatsApp, bKash, IMO, and similar service notes.
- Keeps the shared, native-safe contact payload adapter and uses safe default-account discovery for direct bulk export.
- Fixes the Samsung cloud-default conflict caused by forcing a local raw-contact account.
- Adds resilient native APK update download reuse, progress, verified release assets, and Android installer-permission recovery.
- Keeps Expo OTA updates separate from native APK releases.

Android verification for this release is performed with an Android Emulator / AVD. A Samsung physical-device confirmation remains outstanding.
